[시장 거리별 2D 배경]
MarketEnvironment.asset > 거리별 2D 배경 > Background Layers (근경/중경/원경).
각 레이어의 Distance는 가게 외곽 뒤의 거리, Width/Height는 이미지 크기, Base Height는 이미지 하단 높이, Horizontal Offset은 좌우 위치, Tint는 색조. 기본 거리 26/50/90. 이미지 원본 비율은 3:1.
Use Layered Background 해제 시 기존 단일 배경으로 전환. 가게 확장에는 따라가지만 카메라 이동에는 고정되어 거리별 자연스러운 시차가 발생함.

Horizontal Copies: 가로 반복 수(기본 3). 개별 이미지 비율을 유지하며 배경 좌우 표시 범위를 확장하여 최대 줌아웃과 좌우 이동 시 이미지 끝 노출 방지. Alpha Cutoff: 투명 실루엣 경계 기준(기본 .7).
